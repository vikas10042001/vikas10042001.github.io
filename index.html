Key project

Struts-to-Spring Boot Migration Accelerator

Internal tooling at Coforge

Converting Struts action classes by hand is slow and easy to get wrong. I built a tool that does the first pass and checks its own output before a reviewer sees it.

  1. ParseStatic parsing of the Struts XML configuration.
  2. TranslateLLM-based translation of action classes and configuration.
  3. GenerateSpring Boot controllers, services, and beans as scaffolding.
  4. ValidateLegacy and generated request mappings compared to catch translation gaps.

The migration team adopted it as part of the standard workflow, and manual conversion effort dropped by about 40%.
